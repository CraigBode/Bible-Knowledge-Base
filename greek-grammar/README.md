# Koine Greek Workbook

A single-page study tool for New Testament Greek. Open `index.html` in any web browser — no
server, database, or install required.

- **Paradigms** — polytonic charts for the article, three noun declensions, adjectives, pronouns,
  εἰμί, the full λύω system (all tenses, voices, and moods, plus infinitives and participles),
  contract verbs, second aorist and liquid verbs, and μι-verbs, each with notes on what to memorize.
- **Parsing Drill** — every form in the charts becomes a parsing question. Ambiguous forms accept
  any correct parsing.
- **Vocabulary** — the ~310 words occurring 50+ times in the NT, as flashcards with spaced review.
- **Verses** — 40 short NT texts (NA28/SBLGNT) with every word parsed; tap a word or quiz yourself.

Progress (vocabulary boxes, chosen paradigms) is saved in the browser only. Frequency counts are
approximate. The file has no `<!doctype>` line because the publishing host supplies one; browsers
open it normally.
